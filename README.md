# Severance-fan-page — mon premier site en HTML et CSS

Une page de fan consacrée à la série *Severance* : une bannière, une présentation, une liste de critiques avec liens, et la distribution.

## Pourquoi ce projet
Mon tout premier site web (avril 2023), réalisé pendant un cours Skillshare, avant de passer à JavaScript et à React.

## Ce que j'ai appris
- Structurer une page en HTML : titres, listes, liens.
- Mettre en forme avec des feuilles de style séparées (dossier `CSS/`).
- Utiliser des chemins relatifs pour les images : l'historique montre six commits en quinze minutes pour une image qui ne s'affichait pas, et le chemin faux en était la cause.

## Stack
HTML et CSS, sans outil de construction.

## Lancer en local
Aucune installation. Ouvrir `index.html` dans un navigateur, ou lancer un petit serveur :
```bash
python3 -m http.server 8000   # puis http://localhost:8000
```

## Démo
Pas de démo en ligne.
